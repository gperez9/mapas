# Mapas de España

Aplicación web educativa para practicar el mapa político de España.

## Estado actual

La Iteración 0 técnica deja preparada la base del proyecto:

- scaffold de React + TypeScript + Vite;
- catálogo inicial de comunidades autónomas;
- mapa SVG interactivo de CCAA;
- estilos base con tono lúdico;
- build de producción verificado;
- documentación viva en [`docs/`](./docs/README.md).

## Scripts previstos

```bash
npm install
npm run dev
npm run build
```

## Nota sobre los mapas

El mapa de comunidades autónomas se ha preparado a partir de geometrías oficiales del IGN y se ha adaptado para uso didáctico en la aplicación.
